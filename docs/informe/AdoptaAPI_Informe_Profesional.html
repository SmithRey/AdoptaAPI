1. Resumen ejecutivo

AdoptaAPI es una plataforma tecnológica orientada a centralizar y digitalizar el proceso de adopción de mascotas en Colombia. Conecta fundaciones de rescate animal con adoptantes potenciales mediante una API REST documentada y una interfaz web MVC, reemplazando la gestión fragmentada actual en redes sociales.

AspectoDescripción
ProblemaInformación dispersa, falta de trazabilidad y procesos informales en adopciones
SoluciónAPI centralizada con filtros, flujo de solicitudes con estados y reportes de impacto
UsuariosFundaciones de rescate, adoptantes y visitantes
EntregablesAPI REST, Swagger UI, modelo relacional, diagramas UML, mockups Figma, despliegue Azure
Duración estimada6 semanas (3 sprints + setup)

2. Contexto y objetivos

2.1 Objetivo general

Desarrollar una API REST que centralice y digitalice el proceso de publicación, búsqueda y seguimiento de adopciones de mascotas, conectando de forma ágil y trazable a fundaciones de rescate animal con potenciales adoptantes.

2.3 Descripción del problema

En Colombia, cerca del 58% de los hogares tiene al menos una mascota. La red de rescate es amplia pero informal y atomizada: fundaciones, colectivos y hogares de paso publican en Instagram, Facebook y grupos locales (#AdoptaEnBogota, #AdoptaNoCompres).

  • Dispersión informativa — decenas de perfiles sin catálogo unificado.
  • Falta de confianza — adoptantes verifican manualmente la legitimidad de rescatistas.
  • Proceso intrazable — solicitudes por mensajes privados; refugios saturados más tiempo del necesario.
  • Reportes artesanales — iniciativas como "Plan Padrino" confirman la necesidad de trazabilidad, pero no escalan.

3. Alcance del proyecto

3.1 Dentro del alcance

  • API REST: usuarios, mascotas, solicitudes, reportes
  • Autenticación JWT por rol (fundación / adoptante)
  • Filtros: especie, edad, tamaño, ciudad, estado
  • Swagger UI interactivo
  • Modelo relacional SQL Server + EF Core
  • Interfaz web MVC (cliente de la API)
  • Mockups navegables en Figma
  • Despliegue en Azure App Service

3.2 Fuera del alcance

  • Pasarela de pagos o donaciones
  • Notificaciones push en tiempo real
  • App móvil nativa
  • Verificación legal/judicial de adopciones
  • Verificación automatizada de fundaciones

5. Historias de usuario

HU-01 — Registro de fundación
Como fundación, quiero registrarme, para publicar mascotas.
  • Campos: nombre, email, contraseña, ciudad, organización
  • Email único; contraseña hasheada; tipo Fundacion; HTTP 201
HU-02 — Registro de adoptante
Como adoptante, quiero registrarme, para enviar solicitudes.
  • Campos: nombre, email, contraseña, ciudad; tipo Adoptante; HTTP 201
HU-03 — Inicio de sesión
Como usuario, quiero iniciar sesión, para acceder según mi rol.
  • JWT con claims userId, email, rol; HTTP 401 si inválido
HU-04 — Publicar mascota
Como fundación, quiero publicar una ficha, para que adoptantes la encuentren.
  • Campos obligatorios: nombre, especie, edad, tamaño, ciudad, descripción
  • Estado inicial Disponible; solo rol Fundacion
HU-05 — Buscar mascotas con filtros
Como visitante/adoptante, quiero filtrar mascotas, para encontrar la ideal.
  • Filtros combinables: especie, edad, tamaño, ciudad, estado; paginación; endpoint público
HU-06 — Actualizar o eliminar mascota
Como fundación, quiero editar/eliminar mis fichas, para mantener info actualizada.
  • Solo propietario; no eliminar con solicitudes EnRevision/Aprobada
HU-07 — Ver detalle de mascota
Como adoptante, quiero ver info completa, para decidir adopción.
  • Incluye datos de fundación; HTTP 404 si no existe
HU-08 — Enviar solicitud de adopción
Como adoptante, quiero solicitar adopción, para iniciar el proceso.
  • Estado Pendiente; mascota Disponible; mascota pasa a EnProceso; HTTP 201
HU-09 — Gestionar solicitudes
Como fundación, quiero cambiar estados, para gestionar adopciones.
  • Pendiente→EnRevision→Aprobada|Rechazada→Completada
  • Al aprobar: mascota Adoptada; rechazar otras solicitudes activas
HU-10 — Consultar mis solicitudes
Como adoptante, quiero ver mis solicitudes, para hacer seguimiento.
  • Solo del adoptante autenticado; orden por fecha descendente
HU-11 — Reporte de impacto
Como fundación, quiero ver reporte de mis mascotas, para medir impacto.
  • Totales: disponibles, en proceso, adoptadas; filtro por fechas
HU-12 / HU-13 — Swagger UI y Mockups Figma
  • Swagger en /swagger con JWT; mockups responsive del flujo completo
